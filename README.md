# Uber Data Analysis Dashboard | Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze **150K+ Uber booking records**, focusing on bookings, revenue, cancellations, vehicle performance, payment methods, and customer and driver ratings.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX

## Key Features
- KPI cards and interactive visualizations
- Booking and revenue analysis
- Vehicle and payment method performance
- Cancellation and rating analysis
- Interactive slicers and filters

## Objective
To identify booking trends, evaluate business performance, and generate actionable insights for data-driven decision-making.
